# RecordToday v1.0

## Highlights

- Windows portable package with `RecordToday.exe`
- `todo_data.json` is stored next to the executable for direct-use persistence
- Daily, weekly, and monthly focus statistics
- Task timing, tray support, and report views in one desktop app

## Package Contents

- `RecordToday.exe`
- Qt runtime DLLs and plugin folders required by the app
- `todo_data.json`
- `README.md`
- `LICENSE`

## How To Use

1. Extract `RecordToday-windows-portable-fixed.zip`
2. Open the extracted `RecordToday-windows-portable-fixed` folder and double-click `RecordToday.exe`
3. Keep all files in that folder together so the app can load its runtime DLLs
4. Keep the generated or updated `todo_data.json` in the same folder so data persists automatically
